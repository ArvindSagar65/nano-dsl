nano-dsl :: TUI Execution Architecture

🔒 Security Notice & Execution Boundary:

By design, all DSL commands, rules, and mutating actions are strictly executed inside the Terminal User Interface (TUI). This web dashboard serves as a high-performance, real-time observability and telemetry console (Portainer/Grafana style) to monitor your local system, containers, and EC2 fleet safely without exposing remote command execution endpoints.

💻 Launching the TUI Terminal Console:

nano-dsl

⚡ Sample DSL Commands to try in the TUI:

cpu.util
docker.ps
ec2.list
high_cpu: alert cpu.util > 80 -> log
slack_mem: alert mem.util > 90 -> slack
stop rule high_cpu
